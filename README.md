# MSP Music

一款基于 Electron 的桌面音乐播放器，支持本地音乐播放、在线曲库搜索播放、MV 播放、歌词同步显示等功能。

## 功能特性

### 🎵 本地音乐
- 自动扫描本地音乐文件夹，支持 MP3 / FLAC / WAV / AAC / OGG / M4A 等格式
- ID3 标签自动读取（歌名、歌手、专辑、封面）
- 本地 LRC 歌词自动匹配与同步滚动
- 播放列表管理、随机 / 顺序 / 单曲循环模式
- 音量调节、进度拖动、上一首 / 下一首

### 🌐 在线曲库
| 平台 | 搜索 | 播放 | 歌词 | 封面 | VIP 标识 |
|------|------|------|------|------|----------|
| 网易云音乐 | ✅ | ✅ | ✅ | ✅ | ✅ |
| QQ 音乐 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 哔哩哔哩 (MV) | ✅ | ✅ | — | — | — |

- 搜索结果按来源分组展示，支持按平台筛选
- VIP / 数字专辑歌曲标注，免费歌曲可直接播放
- 在线播放自动获取并同步歌词

### 🎬 MV 播放
- 一键搜索并播放当前歌曲的 B站 MV
- 支持 1080P DASH 音视频流合并播放
- MV 播放进度自动保存，下次播放从上次位置继续
- 退出全屏再返回，MV 画面与进度不丢失
- 系统级全屏切换

### 📺 全屏播放
- 全屏歌词视图，当前行高亮自动滚动
- 自定义背景（图片 / 视频）
- MV 模式下歌词叠加在视频画面上
- 深色 / 浅色主题切换

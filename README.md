# MSP Music

一款基于 Electron 的桌面音乐播放器，支持本地音乐播放、在线曲库搜索播放、MV 播放、歌词同步显示，并内置基于 mpv 的 Bit-perfect 高保真音频引擎。

## 功能特性

### 🎵 本地音乐
- 自动扫描多个本地音乐文件夹，支持 MP3 / FLAC / WAV / WMA / AAC / OGG / M4A / AIFF / OPUS / WavPack / APE / TAK / DSF / DFF 等格式
- ID3 标签自动读取（歌名、歌手、专辑、封面）
- 本地 LRC 歌词自动匹配与同步滚动
- **CUE 整轨分轨**：自动识别 CUE 分轨表，按单曲浏览播放（兼容 GBK 编码、CUE 与音频扩展名不一致等常见情况），同专辑曲目 **Gapless 无缝播放**
- **DSD 原生支持**：DSF / DFF 文件通过 DoP 直通输出
- 播放列表管理、随机 / 顺序 / 单曲循环模式（随机支持「全部 / 专辑 / 艺术家」三种范围）
- **AB 复读**：依次设定 A 点、B 点后在区间内循环，适合练琴、学歌、听写
- **断点续播**：自动记住每首歌的播放位置，下次打开从上次处继续
- 我的收藏、最近播放、每日推荐
- 音量调节、进度拖动、上一首 / 下一首

### 🎧 高保真音频引擎（Bit-perfect）
播放器内置独立的 mpv 音频引擎（随安装包附带，无需另行安装），面向发烧友提供直通输出：

- **WASAPI 独占模式**：绕过系统混音器，音频数据原样送往 DAC
- 源文件采样率 / 位深 / 声道信息不经过任何重采样改动（关闭 DSP 时零处理直通）
- 自由选择 WASAPI 输出设备
- 可选强制重采样（SRC，swresample）与量化抖动（Dither）
- 软件音量（独占模式下调节音量）/ 硬件系统音量两种方案
- **信号路径面板**：实时显示当前歌曲的来源编码、采样率、位深、声道、DSP 处理链路、DAC 输出参数与时钟流向，Bit-perfect 状态一目了然
- 在线歌曲 / 未开启引擎的本地歌曲自动走常规播放通路，两条通路均支持调音效果

### 🎛️ 调音台 DSP
两条播放通路均提供丰富的声音调节（引擎通路由 mpv/FFmpeg 处理，常规通路由 Web Audio 等效处理）：

- 10 段图形均衡器（31 Hz – 16 kHz）+ 前置增益
- 声道平衡、立体声宽度（0% 单声道 – 200% 拓宽声场）
- 合并单声道、左右声道交换、左右声道反相
- Crossfeed 交叉馈送（减轻耳机「头中效应」）
- 压缩器 / 限幅器（阈值、比率、启动释放时间等可调）
- 多声道左右延迟校正
- FIR 卷积（支持自定义脉冲响应文件，耳机补偿 / 房间校正）
- 卷积混响（常规通路）

### 🏷️ 元数据自动刮削
本地歌曲缺少标签或封面时，可一键批量补全信息，多源自动择优：

**QQ 音乐 → 网易云音乐 → MusicBrainz / Cover Art Archive → LRCLIB**

自动回填歌名、歌手、专辑、封面与歌词，刮削过程中页面实时显示进度，封面增量更新不闪烁。

- 退出全屏再返回，MV 画面与进度不丢失
- 系统级全屏切换

### 📺 全屏播放与界面

- 深色 / 浅色主题切换，自动适配

## 快速开始

首次启动后在「设置 → 音乐文件夹」中添加本地音乐目录即可扫描入库；在「音频输出」中开启 Bit-perfect 引擎并选择输出设备。
